##  How It Works (Simple Steps)

1. **Read Video** → Loads frames one by one
2. **Find Movement** → Detects what's moving using optical flow
3. **Extract Features** → Measures direction and speed of movement
4. **Classify** → AI decides if movement is normal or weird
5. **Draw Boxes** → Puts yellow rectangles around anomalies
6. **Save Results** → Saves images with boxes drawn
7. **Calculate Scores** → Shows how accurate the detection was

##  Metrics Explained

### Precision
- **What**: How many detected anomalies were actually anomalies?
- **Formula**: True Positives / (True Positives + False Positives)
- **Example**: If it found 100 anomalies and 85 were real → 85% precision

### Recall
- **What**: How many real anomalies did we find?
- **Formula**: True Positives / (True Positives + False Negatives)
- **Example**: If there were 100 real anomalies and we found 78 → 78% recall

### F1-Score
- **What**: Balance between precision and recall
- **Formula**: 2 × (Precision × Recall) / (Precision + Recall)
- **Range**: 0-1 (1 is perfect)

### EER (Equal Error Rate)
- **What**: Point where false alarms = missed detections
- **Range**: 0-1 (lower is better)
- **Good**: < 0.2

##  Troubleshooting

###  Error: "Module cv2 not found"
```powershell
pip install opencv-python opencv-contrib-python
```

### ❌ Error: "No module named 'sklearn'"
```powershell
pip install scikit-learn
```

### ❌ Error: "Directory not found"
- Make sure you have the UCSD dataset
- Check path: `UCSD_Anomaly_Dataset.v1p2/UCSDped1/Test/`

### ❌ Error: "features/ not found"
- The system needs pre-extracted training features
- Check if `features/` directory exists with `features_test_UCSDped1*` files

## 💡 Pro Tips

1. **Faster Processing**: Increase `detect_interval` to 10 or 15
2. **More Accurate**: Decrease `detect_interval` to 3 or 1
3. **Less Sensitive**: Increase `mag_threshold` to 1e-2
4. **More Sensitive**: Decrease `mag_threshold` to 1e-4
5. **Bigger Boxes**: Increase `n` to 20 or 30
6. **Smaller Boxes**: Decrease `n` to 5
