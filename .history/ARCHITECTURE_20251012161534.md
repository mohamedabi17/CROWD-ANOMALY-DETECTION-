│  └────────┬─────────┘          └────────┬─────────┘                │
│           │                              │                          │

│                      ▼                                               │
│         ┌────────────────────────┐                                  │
│         │  Background Subtraction │                                 │
│         │  (MOG Algorithm)        │                                 │
│         └────────────────────────┘                                  │
│                      │                                               │
│                      ▼                                               │
│         ┌────────────────────────┐                                  │
│         │  Foreground Mask       │                                  │
│         └────────────────────────┘                                  │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   OPTICAL FLOW ANALYSIS                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  Farneback Dense Optical Flow                                       │
│  ┌─────────────────────────────────────────────────────────┐       │
│  │  • Calculate flow vectors (fx, fy)                      │       │
│  │  • Compute magnitude: sqrt(fx² + fy²)                   │       │
│  │  • Compute angle: arctan2(fy, fx)                       │       │
│  │  • Discretize into 8 directional bins (0-360° / 45°)   │       │
│  │  • Filter by magnitude threshold (1e-3)                 │       │
│  └─────────────────────────────────────────────────────────┘       │
│                                                                      │
│  Output: Direction Bins [0-8] + Magnitude Map                       │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   FEATURE EXTRACTION                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  Divide Frame into Grid (10x10 pixel regions)                       │
│                                                                      │
│  For each region:                                                   │
│  ┌─────────────────────────────────────────────────────────┐       │
│  │  1. Histogram of 9 direction bins                       │       │
│  │  2. Foreground pixel count                              │       │
│  │  3. Average flow magnitude                              │       │
│  │  4. Spatial coordinates (i, j)                          │       │
│  └─────────────────────────────────────────────────────────┘       │
│                                                                      │
│  Feature Vector: [bin0, bin1, ..., bin8, fg_count, mag, i, j]      │
│                   (Total: 13 features per region)                   │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    CLASSIFICATION MODULE                             │

│                                                                      │

│  │   Decision Tree Classifier                  │                    │
│  │   • max_depth = 5                          │                    │
│  │   • Trained on pre-extracted features      │                    │
│  │   • Binary classification: 0=Normal, 1=Anomaly │               │
│  └────────────────────────────────────────────┘                    │
│                      │                                               │
│                      ▼                                               │
│  ┌────────────────────────────────────────────┐                    │
│  │   Predictions per Region                   │                    │
│  │   [0, 0, 1, 0, 1, 0, ...]                 │                    │
│  └────────────────────────────────────────────┘                    │
│                                                                      │

                                   │
                                   ▼

│  ┌─────────────────────────────────────────────────────────┐       │
│  │  • Draw yellow bounding box (255, 255, 0)              │       │
│  │  • Record frame number                                  │       │
│  │  • Save annotated frame to output_folders/outN/        │       │
│  └─────────────────────────────────────────────────────────┘       │
│                                                                      │
│  Output Format: frame001.jpg, frame002.jpg, ...                     │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼

│                      EVALUATION MODULE                               │

│  Frame-Level Metrics:                                               │
│  ┌─────────────────────────────────────────────────────────┐       │
│  │  • Precision = TP / (TP + FP)                           │       │
│  │  • Recall = TP / (TP + FN)                              │       │

│                                                                      │

═══════════════════════════════════════════════════════════════════════
                         KEY PARAMETERS
═══════════════════════════════════════════════════════════════════════

Region Size (n):              10 pixels
Detection Interval:           Every 5th frame
Magnitude Threshold:          1e-3
Direction Bins:               8 (45° each) + 1 (no motion)
Classifier:                   Decision Tree (max_depth=5)
Background Subtractor:        MOG (Mixture of Gaussians)
Optical Flow Method:          Farneback Dense Flow
